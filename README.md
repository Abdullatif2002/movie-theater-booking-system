# movie-theater-booking-system
A web-based movie theater booking system with interactive seat selection, showtime management, and a distinctive user experience.

## Project Overview

This project aims to digitalize movie theater operations with a customer-friendly booking experience and management tools for theater staff.

## Planned Features

- Browse movies and view movie details
- Explore showtimes for different theaters
- Interactive seat selection and seat availability
- Prevent double booking of the same seat
- Ticket reservation and payment workflow
- Admin and staff management features
- Accessible seating options
- Corporate private screening requests

## Planned Technology Stack

- Frontend: React
- Backend: Node.js and Express.js
- Database: PostgreSQL
- Testing: Cypress
- Version control: Git and GitHub
- Deployment: Azure, subject to course requirements

## User Roles

- Customer
- Staff
- Administrator
